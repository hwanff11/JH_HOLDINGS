# JH AUTO 실거래 Telegram 메시지 기준

> 적용 대상: **JDSS 3.2.2 + JH AUTO 1.0.0 실계좌 운영**
>
> 목적: 운영자가 10초 안에 **자동운용 상태, 현재 수익률, 내 돈에 미치는 영향, 필요한 행동**을 판단하도록 표현을 통일합니다.

전략 규칙은 [`JDSS_FINAL_SPEC.md`](JDSS_FINAL_SPEC.md), 자동매매 계약은 [`JH_AUTO_SPEC.md`](JH_AUTO_SPEC.md)를 따릅니다.

## 1. 메시지 우선순위

모든 실거래 메시지는 가능한 한 다음 순서로 읽히게 합니다.

1. **현재 상태** — 정상 / 시작 대기 / 자동점검 / 안전정지 / 대표 긴급정지
2. **현재 성과** — 자동운용자산 / 누적손익 / 누적수익률
3. **자금 범위** — 기준자금 / 자동운용비율 / 목표·현재 허용원금
4. **오늘 영향** — 신규 자동매수 / 위험축소 / 진행 중 주문
5. **운영자 행동** — 없음 / 확인 필요 / `/halt` / `/account` / `/order`
6. **상세정보** — 종목, 수량, 가격, 목표비중, 내부 상태

정상일 때는 `대표님 행동: 없음`을 명확하게 표시합니다.

---

## 2. 버전 표기

투자판단과 자동실행 버전을 분리합니다.

```text
투자전략   JDSS 3.2.2
자동매매   JH AUTO 1.0.0
```

`JH AUTO 1.0.0`을 `JDSS 4.x`처럼 표시하지 않습니다.

---

## 3. 자금 표현

다음 용어를 고정합니다.

| 표시 | 뜻 |
|---|---|
| 운용 기준자금 | 100% 자동운용 시 기준이 되는 운영자 설정 원금 |
| 자동운용비율 | 기준자금 중 JH AUTO에 맡긴 비율 |
| 목표 자동원금 | 기준자금 × 자동운용비율 |
| 현재 허용원금 | 50→75→100 자금단계까지 반영해 실제 위험예산에 사용할 수 있는 원금 |
| 현재 투자액 | QQQ/TQQQ/SOXL 실제 평가액 합계 |
| 대기현금 | JH AUTO 관리 현금 |

`자동운용비율 20%`를 `시장 투자비율 20%`라고 표현하지 않습니다. 실제 시장노출은 JDSS가 결정합니다.

---

## 4. 성과 표현

### 전체 포트폴리오

기본 세트:

```text
자동운용자산      $10,438
누적 운용손익      +$438
누적 운용수익률    +4.38%
```

누적수익률은 기준자금·자동운용비율 변경에 따른 외부자금 유입·회수 영향을 제거한 단위가치 기반 성과입니다.

### 종목별

```text
QQQ
평가손익     +$139.50
보유수익률     +2.21%
```

`보유수익률`은 현재 보유분 기준입니다. 종목별 수익률을 더해서 포트폴리오 합계수익률로 표시하지 않습니다.

## 5. `/dashboard` 메시지 필수항목

첫 화면에서 다음이 보여야 합니다.

```text
[JH_HOLDINGS 자동운용 대시보드]

현재 상태
투자전략 / 자동매매 버전

자동운용 자금
운용 기준자금
자동운용비율
목표 자동원금
현재 허용원금
자금투입 단계

현재 성과
자동운용자산
누적 운용손익
누적 운용수익률
투자중 / 현금
최고 평가액 / HWM75 위험한도

안전상태
최초 시작승인
대표 긴급정지
시스템 임시격리
진행 중 주문
```

상세 종목정보는 `/portfolio`로 넘기고 대시보드를 지나치게 길게 만들지 않습니다.

---

## 6. `/portfolio` 메시지 필수항목

전체:

- 자동운용자산
- 누적 운용손익
- 누적 운용수익률
- 현재 투자액

QQQ/TQQQ/SOXL 각각:

- 보유수량
- 목표수량
- 평균단가
- 현재가
- 평가액
- 평가손익
- 보유수익률
- 목표비중

평단이 없거나 보유수량이 0이면 수익률은 0% 또는 `-`로 표시하고 임의 계산하지 않습니다.

---

## 7. `/today` 메시지 필수항목

`/today`는 더 이상 수동 BUY 승인화면이 아닙니다.

필수표시:

- 전체 누적수익률·누적손익
- 현재 미국장 상태
- 각 종목 `현재수량 → 목표수량`
- 각 종목 보유수익률
- 자동매수/위험축소 필요 수량
- 현재 자동 BUY가 차단돼 있다면 이유

정상 AUTO 상태에서는 `대표님이 별도로 개별 BUY를 승인할 작업은 없습니다.`를 표시합니다.

---

## 8. 최초 시작 전 메시지

첫 JH AUTO 배포 뒤 정상 기본상태:

```text
JH AUTO 1.0.0 준비 완료

현재 상태       최초 시작 대기
최초 시작승인   미승인
현재 허용원금   $0
실제 신규 BUY   차단
```

기준자금·자동운용비율을 설정해도 최초 시작승인 전에는 `실제 BUY 차단`을 계속 명확하게 표시합니다.

`/auto start` 최종 확인 뒤에는:

```text
최초 시작승인 완료
현재 허용원금(1단계)  $X
이 버튼에서 실제 BUY   0건
```

을 표시합니다.

---

## 9. 자금변경 메시지

기준자금/자동운용비율 변경은 적용 전에 반드시 현재값·변경값·예상 목표원금을 보여줍니다.

예:

```text
자동운용비율 변경
현재 20% → 변경 50%
목표 자동원금 $10,000 → $25,000
추가 위험원금은 50→75→100 단계로 열립니다.
```

감액은:

```text
자동운용비율 감소
목표 자동원금 $25,000 → $10,000
위험감소는 단계대기 없이 새 목표에 반영됩니다.
```

처럼 표시합니다.

## 10. 주문 상태 표현

| 내부 상태 | 운영자 표시 | 의미 | 처리 |
|---|---|---|---|
| `CREATED` / `SUBMITTED` / `PENDING` | **실주문 접수** | 주문 접수, 전량체결 전 | 주문감시 |
| `PARTIAL_FILLED` | **실주문 부분체결** | 일부 체결 | 잔량 blind 재주문 금지 |
| `FILLED` | **실주문 체결 완료** | 전량체결 확인 | 원장반영·계좌대조 |
| `REJECTED` | **실주문 거부** | 주문 거부 | 최신 조건에서 재판단 |
| `CANCELED` | **실주문 취소 확인** | 원주문 취소 확인 | 다음 주기 재판단 |
| `REPLACED` | **실주문 변경 확인 필요** | 주문상태 변경 | 원주문 우선 확인 |
| `UNKNOWN` | **실주문 결과 확인 필요** | 성공/실패 확정 불가 | 재주문 금지·안전정지 |

`UNKNOWN`을 `실패`라고 번역하지 않습니다.

## 11. 자동주문 메시지

새 자동 BUY가 제출되면 최소 다음을 보여줍니다.

```text
[JH AUTO 자동주문]
종목
주문수량
현재 체결수량
주문상태
```

그리고:

`다음 신규 BUY는 주문감시와 계좌·원장 대조를 다시 통과한 뒤에만 진행됩니다.`

를 명시합니다.

---

## 12. 정지 상태 표현

### 대표 긴급정지

```text
🚨 대표 긴급정지 · 신규 자동매수 차단
```

시스템 자동해제 가능하다고 표현하지 않습니다.

### 시스템 임시격리

```text
🛡️ 자동점검·임시격리 · 신규 자동매수 일시 차단
```

이미 최초 시작승인이 있고 모든 안전조건이 정상으로 재확인될 때 자동복귀할 수 있는 상태입니다.

### 안전정지

```text
🚨 안전정지(SAFE_MODE) · 신규 자동매수 차단
```

상태를 확정할 때까지 보호 중이라는 의미를 함께 설명합니다.

---

## 13. 위험축소 SELL

위험을 줄이는 SELL은 BUY와 분리해 표현합니다.

```text
위험축소 진행
→ 체결확인
→ 원장반영
→ 계좌대조
→ 이상 없음
→ 다음 신규 BUY 가능
```

매도가 미완료이거나 결과불명인 상태에서 `신규매수 가능` 문구를 표시하지 않습니다.

---

## 14. 아침 브리핑 표준

정상 예시:

```text
[JH AUTO 아침 브리핑]

오늘의 상태
자동운전 정상

자금
기준자금        $50,000
자동운용비율    20%
목표 자동원금   $10,000
현재 허용원금   $10,000

성과
누적 운용손익   +$438
누적 운용수익률 +4.38%

오늘 예상
신규 자동매수   1건
위험축소        없음

안전
계좌·원장       정상
미확인주문      없음

대표님 행동
없음
```

오류가 있으면 `대표님 행동 없음` 대신 확인해야 할 명령을 한두 개만 표시합니다.

---

## 15. 메시지에서 금지할 표현

- 자동화비율 = 실제 투자비율이라고 단정
- 시작버튼 = 즉시 매수버튼이라고 표현
- 배포 완료 = 자동매매 시작이라고 표현
- `UNKNOWN = 실패`
- 취소 요청 접수 = 취소 완료
- 대표 `/halt` = 시스템이 알아서 해제
- 종목별 수익률 합계 = 전체 수익률
- 기준자금 증가 = 투자수익 증가
- 비관리 계좌자산 = JH AUTO 자산

---

## 16. 운영 메시지의 목표

정상상태에서 Telegram은 사용자의 매수승인을 요구하지 않습니다.

좋은 정상 메시지는 다음 네 질문에 바로 답해야 합니다.

1. 자동운용이 정상인가?
2. 지금 얼마를 맡기고 얼마가 실제 허용됐는가?
3. 전체 및 종목별 성과가 어떤가?
4. 내가 지금 할 일이 있는가?

JH AUTO의 기본 답은 **`정상 / 설정된 범위 / 명확한 성과 / 운영자 행동 없음`**입니다.
