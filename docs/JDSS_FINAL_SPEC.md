# JDSS 3.2.2 공식 투자전략 사양

현재 공식 전략 ID는 **`JDSS-3.2.2-RS6M-ONEWAY-HWM75`**입니다.

이 문서는 **무엇을 어떤 비중으로 보유할지 결정하는 투자전략 규범**을 소유합니다. 실제 자동운용 자금설정·자동승인·Telegram·최초 시작·주문 안전상태는 [`JH_AUTO_SPEC.md`](JH_AUTO_SPEC.md)가 소유합니다.

정확한 실행 숫자는 [`../strategy.yaml`](../strategy.yaml), 실제 구현은 [`../src/jd_holdings/`](../src/jd_holdings/), 현재 배포상태는 [`../CURRENT_WORK.md`](../CURRENT_WORK.md)가 기준입니다.

## 1. 전략과 자동매매의 경계

JH_HOLDINGS는 두 버전을 분리합니다.

| 구분 | 현재 | 책임 |
|---|---|---|
| 투자전략 | JDSS 3.2.2 | 시장판단, 목표노출, ETF 배분, RS6M, 추가 레버리지, HWM75 공식 |
| 자동매매 | JH AUTO 1.0.0 | 기준자금, 자동운용비율, 실제 위험원금, 자동주문, 성과회계, 안전정지 |

JH AUTO 도입은 JDSS의 시장판단 수학을 바꾸지 않습니다.

---

## 2. 관리 자산

목표배분 종목:

- **QQQ** — 기본 나스닥100 코어
- **TQQQ** — 나스닥100 3배 레버리지
- **SOXL** — 반도체 3배 레버리지

판단용 기준:

- **SOXX** — 반도체 상대강도 RS6M 기준
- **SPY** — 기존 가상 추가레버리지 신호 엔진의 시장국면 입력
- **SMH** — SOXL 보조 섹터 가드. 핵심 RS 배분 기준이 아님

SGOV 자동운용은 현재 OFF입니다.

---

## 3. 전략 기준자금과 실제 운용자금

연구·백테스트·전략 검증의 canonical 기준자금은 **$50,000**입니다.

그러나 JH AUTO 실거래에서는 실제 전략 위험원금이 운영자가 정한:

```text
운용 기준자금 × 자동운용비율
```

및 현재 50→75→100 자금개방 단계에 따라 달라질 수 있습니다.

따라서 `$50,000`은 **JDSS 전략 연구의 기준점**이고, 실거래에서 항상 $50,000 전체를 자동투자한다는 의미가 아닙니다.

실제 자금·성과 회계는 [`JH_AUTO_SPEC.md`](JH_AUTO_SPEC.md)를 따릅니다.

## 4. HWM75 통제복리 공식

현재 위험원금 `P`, 최고 자동운용 평가액 `H`, 현재 평가액 `E`일 때:

```text
위험예산 = min(E, P + 0.75 × max(0, H - P))
```

원칙:

- 새 최고자산 초과이익의 75%만 위험예산 증가에 반영
- 나머지 25%는 관리현금으로 남지만 추가 위험예산으로 쓰지 않음
- 손실 시 외부자금을 자동보충하지 않음
- 외부자금 위임 증가·감소를 투자수익으로 계산하지 않음
- 최고자산 갱신은 완결 거래일 평가 기준

canonical 백테스트에서는 `P=$50,000`입니다. JH AUTO 실거래에서는 현재 허용원금이 `P` 역할을 합니다.

## 5. QQQ 목표노출

사용 지표:

- SMA50
- SMA200
- 21 / 63 / 126 거래일 수익률
- SMA200의 21거래일 기울기
- QQQ 20거래일 연환산 변동성

기본 판정:

1. warmup 부족 → 1.0x
2. 20일 연환산 변동성 ≥ 30% → 0.5x
3. 종가 ≤ SMA200 → 1.0x
4. SMA50>SMA200이고 63d>0, 126d>0 → 1.5x
5. 다음 다섯 조건 중 3개 이상 → 1.25x
   - 21d>0
   - 63d>0
   - 126d>0
   - SMA50>SMA200
   - SMA200 21일 기울기>0
6. 나머지 → 1.0x

새 달 첫 거래일 완결 종가에서 전체 레짐을 다시 판단합니다.

월중 QQQ 변동성이 30% 이상이 되면 0.5x로 감속할 수 있습니다. 같은 달 안에서 위험노출을 다시 상향하지 않습니다.

---

## 6. 목표노출의 ETF 배분

1.0x 이하에서는 QQQ만 사용합니다.

1.0x 초과분은 3배 ETF로 합성합니다.

```text
3배 ETF sleeve = (목표노출 - 1) / 2
```

| 목표노출 | QQQ | 3배 ETF sleeve | 전략상 현금 |
|---:|---:|---:|---:|
| 0.5x | 50% | 0% | 50% |
| 1.0x | 100% | 0% | 0% |
| 1.25x | 87.5% | 12.5% | 0% |
| 1.5x | 75% | 25% | 0% |

## 7. RS6M 반도체 상대강도

- 기준 ETF: SOXX
- lookback: 126 거래일

ON 조건:

```text
SOXX 126d 수익률 > 0
AND
SOXX 126d 수익률 > QQQ 126d 수익률
```

동작:

- RS6M OFF → 3배 sleeve 100% TQQQ
- RS6M ON → 3배 sleeve 50% TQQQ + 50% SOXL
- 월중 ON 조건 상실 → SOXL 부분을 TQQQ로 축소
- 같은 달 SOXL 재진입 금지
- 다음 월 reset에서 다시 판정

SOXX는 production frozen 기준입니다. 연구결과만으로 자동 변경하지 않습니다.

---

## 8. 최대 5% 추가 레버리지

기존 H40-S3 과매도·반등 로직은 독립 자금전략이 아니라 **가상 추가레버리지 신호**로 사용합니다.

- TQQQ 가상 cycle만 활성 → QQQ 최대 5%를 TQQQ로 이동
- SOXL 가상 cycle만 활성 → QQQ 최대 5%를 SOXL로 이동
- 둘 다 활성 → 총 5%를 2.5%씩 배분
- 가상 활성상태는 미래데이터 사용을 막기 위해 한 거래일 지연 반영

정상 V3.2.2 allocation에서 과거 직접 H40 포지션/TP plan을 실제 독립슬리브로 유지하지 않습니다.

## 9. 완결봉과 실행시점

전략판단과 실제 주문은 시간을 분리합니다.

```text
미국 거래일 완결봉
→ 전략 목표비중 generation 저장
→ 다음 미국 거래일 세션
→ 최신 실행가격으로 목표 정수주 수량 고정
→ 실제 보유·미체결과 차이 계산
```

신호가 금요일 완결봉에서 생성됐다면 금요일 장후에 새 목표를 실행하지 않고 다음 미국 거래일 기준으로 넘어갑니다.

JDSS 전략 자체는 세션별 가격품질 정책을 소유하지 않습니다. JH AUTO 1.0.0 자동 BUY는 안전성 강화를 위해 **미국 정규장만** 사용합니다.

---

## 10. 목표수량

각 종목의 목표수량은 현재 전략 위험예산과 목표비중을 실제 실행가격/수수료에 적용해 정수주로 계산합니다.

중요 원칙:

- 먼저 자금을 축소한 뒤 그 자금에서 정수주를 새로 계산
- `$50,000 목표수량 × 자동운용비율`처럼 주식 수를 단순 비례축소하지 않음
- 현재 보유수량과 이미 주문된 수량을 다시 차감
- 목표가 바뀌면 오래된 주문/신호를 그대로 이어받지 않음

즉 항상 최신:

```text
목표수량 - 실제 보유수량 - 주문/미반영 체결수량
```

으로 gap을 계산합니다.

## 11. 위험축소 SELL 우선

같은 목표변경에서 매도와 매수가 함께 필요하면 위험축소 SELL이 항상 우선입니다.

```text
기존 주문 상태 최신화
→ 위험축소 SELL
→ 종료상태 확인
→ 실제 체결만 원장반영
→ 계좌·원장 대조
→ 안전정지 없음 확인
→ 신규 BUY 가능
```

열린 위험축소 SELL이 있거나 결과를 확정할 수 없으면 신규 BUY를 허용하지 않습니다.

위험축소 SELL은 자동화 대상이며 JH AUTO의 신규 BUY 정지와 독립적으로 위험을 낮추는 방향으로 동작할 수 있습니다.

## 12. BUY 승인 방식: 전략이 아닌 실행계층 책임

과거 V3.2.2 운영은 사람이 Telegram에서 2단계 BUY 승인을 수행했습니다.

JH AUTO 1.0.0에서는 **기존 2단계 검증코드를 그대로 재사용하되 승인 주체가 자동실행 계층으로 바뀝니다.**

따라서 다음은 JDSS 전략변경이 아닙니다.

```text
기존: 전략 → 사람 review → 사람 execution → OrderManager
AUTO: 전략 → 자동 review → 자동 execution → OrderManager
```

정확한 최초 시작승인·자동주문·정지·UNKNOWN 계약은 [`JH_AUTO_SPEC.md`](JH_AUTO_SPEC.md)를 따릅니다.

## 13. 자금투입 50→75→100

비율 자체는 기존 최초진입 안전철학을 유지합니다.

JH AUTO에서는 이 기능을 **전략 목표비중 변경이 아니라 새 자동운용 원금 개방**으로 관리합니다.

- 최초 자동운용 원금: 50 → 75 → 100%
- 기준자금/자동운용비율 증가 시: 추가된 원금만 50 → 75 → 100%
- 현재 단계의 목표수량이 실제로 충족된 뒤 최소 3 미국 거래일 필요
- 위험감소는 단계대기 없이 즉시 반영

운영자는 `/onboarding`을 매 단계 누르지 않습니다. `/auto`가 상태를 보여주고 안전조건 충족 시 자동진행합니다.

## 14. 데이터 fail-closed

전략에 직접 필요한 데이터는 확인할 수 없으면 계산을 중단합니다.

- QQQ 핵심 추세 데이터
- TQQQ/SOXL 전략 입력
- SOXX RS6M

SMH처럼 설정상 보조 기준이고 `warn_and_allow`가 명시된 데이터는 실패했다고 오래된 값을 강제로 대입하지 않습니다. 사용 가능한 허용기준만 적용하고 경고를 남깁니다.

실제 주문가격은 전략 일봉과 별도로 증권사 최신시세 안전검증을 통과해야 합니다.

## 15. 비용·정수주·백테스트 일치

현재 canonical 전략은:

- 매수 수수료 0.1%
- 매도 수수료 0.1%
- 기본 백테스트 슬리피지 0.1%
- 정수주
- 완결봉 판단 → 다음 거래일 실행

을 사용합니다.

자동운용비율이 100%이고 현재 허용원금이 canonical $50,000이며 동일 가격을 사용한다면 JH AUTO 목표수량은 기존 V3.2.2 수량 산식과 동일해야 합니다.

## 16. 백테스트와 실거래 성과의 구분

JDSS 백테스트는 전략 자체의 품질을 평가합니다.

JH AUTO 실거래 성과는:

- 사용자가 정한 운용 기준자금
- 자동운용비율
- 실제 체결가
- 정수주 차이
- 실제 수수료
- 자금 증액·감액

을 포함하므로 백테스트 계좌와 금액이 다를 수 있습니다.

자동운용 성과표시는 외부자금 흐름을 제거한 시간가중 단위가치 방식이며 [`JH_AUTO_SPEC.md`](JH_AUTO_SPEC.md)를 따릅니다.
